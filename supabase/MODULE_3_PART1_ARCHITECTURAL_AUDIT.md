### 🔴 [ত্রুটি ১: ক্রিটিক্যাল] বিপজ্জনক গ্লোবাল ক্লিক হাইজ্যাকিং (`document.addEventListener`)
* **ফাইল:** `src/components/category-drawer/CategoryDrawer.tsx` (Lines 102–125)
* **ত্রুটির বিবরণ:**
  ```typescript
  const triggerBtn = target.closest(
    '[data-drawer-trigger="category"], [aria-label*="সকল বিভাগ"], [aria-label*="ক্যাটাগরি"]'
  ) || (target.closest('button') && target.closest('button')?.textContent?.includes('বিভাগ') ? target.closest('button') : null);
  if (triggerBtn) {
    e.preventDefault();
    useCategoryDrawer.getState().openDrawer();
  }
  ```
  এটি অত্যন্ত ঝুঁকিপূর্ণ ও ক্ষতিকর অ্যান্টি-প্যাটার্ন। অ্যাপ্লিকেশনের যেকোনো স্থানে (সার্চ ক্যাটাগরি ড্রপডাউন, ফিল্টার প্যানেল, অ্যাডমিন প্যানেল বা ফর্ম) কোনো বাটনে "বিভাগ" শব্দটি থাকলে সেই বাটনের নিজস্ব অ্যাকশন বাতিল (`e.preventDefault()`) হয়ে অনাকাঙ্ক্ষিতভাবে ক্যাটাগরি ড্রয়ার ওপেন হয়ে যাবে!
* **বাধ্যতামূলক সংশোধন:**
  - `CategoryDrawer.tsx` থেকে এই অস্বচ্ছ DOM ইভেন্ট লিসেনারটি সম্পূর্ণরূপে মুছে ফেলতে হবে।
  - `Header.tsx`-এর ভেতরে থাকা "সকল বিভাগ" বাটনে সরাসরি `useCategoryDrawer().openDrawer` অথবা `<HamburgerTrigger />` কম্পোনেন্ট যুক্ত করতে হবে।

### 🔴 [ত্রুটি ২: ক্রিটিক্যাল] ব্রাউজার হিস্ট্রি লিক ও ব্যাক বাটন স্ট্যাক পলিউশন (Android / Browser Back Bug)
* **ফাইল:** `src/components/category-drawer/CategoryDrawer.tsx` (Lines 65–78)
* **ত্রুটির বিবরণ:**
  ```typescript
  useEffect(() => {
    if (!isOpen) return;
    window.history.pushState({ categoryDrawerOpen: true }, '');
    const handlePopState = () => { closeDrawer(); };
    window.addEventListener('popstate', handlePopState);
    return () => { window.removeEventListener('popstate', handlePopState); };
  }, [isOpen, closeDrawer]);
  ```
  ড্রয়ার ওপেন হলে `history.pushState()` করা হচ্ছে। ব্যবহারকারী ব্রাউজারের ব্যাক বাটন চাপলে ড্রয়ার বন্ধ হয়, কিন্তু **ইউজার যদি ক্লোজ 'X' বাটন, ব্যাকড্রপ ক্লিক, ESC কি বা বাঁয়ে সোয়াইপ করে ড্রয়ার বন্ধ করে—তবে পুশ করা হিস্ট্রি স্টেটটি আর কখনোই `history.back()` দিয়ে পপ করা হয় না!**
  ফলে ইউজার ৫ বার ড্রয়ার খুললে ও বন্ধ করলে ব্রাউজারের হিস্ট্রি স্ট্যাকে ৫টি ভুয়া এন্ট্রি জমে যায়। ইউজার যখন আগের পেজে যেতে চাইবে, তাকে ৫ বার ব্যাক বাটন চাপতে হবে এবং কিছুই ঘটবে না!
* **বাধ্যতামূলক সংশোধন:**
  - বাইডাইরেকশনাল হিস্ট্রি ম্যানেজমেন্ট বাস্তবায়ন করুন: ইউআই অ্যাকশন (X বাটন, ব্যাকড্রপ, ESC, সোয়াইপ) দিয়ে ড্রয়ার বন্ধ করার সময় যদি `window.history.state?.categoryDrawerOpen` ট্রু থাকে, তবে স্বয়ংক্রিয়ভাবে `window.history.back()` কল করে স্ট্যাক ক্লিন করতে হবে, যেন কোনো ফ্যান্টম হিস্ট্রি এন্ট্রি না থাকে।

### 🔴 [ত্রুটি ৩: ক্রিটিক্যাল A11y] অ্যাক্সেসিবল কিবোর্ড ফোকাস ট্র্যাপের অনুপস্থিতি (WCAG 2.1 AA Non-Compliance)
* **ফাইল:** `src/components/category-drawer/CategoryDrawer.tsx`
* **ত্রুটির বিবরণ:**
  কোডের কমেন্টে বলা হয়েছে `A11y focus trap`, কিন্তু বাস্তবে কোনো ফোকাস ট্র্যাপ কোড লেখা হয়নি!
  ড্রয়ারটি যখন খোলা থাকে (`role="dialog"` এবং `aria-modal="true"`), কিবোর্ডের `Tab` বাটন চাপলে ফোকাস ড্রয়ারের বাইরে চলে যায় এবং ডার্ক ব্যাকড্রপের পেছনের হেডারের লিঙ্ক ও সার্চবারে অদৃশ্যভাবে ফোকাস ঘুরতে থাকে।
* **বাধ্যতামূলক সংশোধন:**
  - ড্রয়ার খোলার সাথে সাথে ড্রয়ারের ক্লোজ 'X' বাটনে বা প্রথম ফোকাসযোগ্য উপাদানে অটো-ফোকাস দিন।
  - `Tab` এবং `Shift+Tab` ইন্টারসেপ্ট করে ফোকাসকে ড্রয়ারের ফোকাসযোগ্য উপাদানের (`button, [href], input, select`) ভেতরে চক্রাকারে আটকে রাখুন (শেষ আইটেমে Tab চাপলে ক্লোজ বাটনে এবং ক্লোজ বাটনে Shift+Tab চাপলে শেষ আইটেমে যাবে)।

### ⚠️ [ত্রুটি ৫: ইউএক্স ও টাচ] ত্রুটিপূর্ণ সোয়াইপ-টু-ক্লোজ মেকানিজম (মোবাইল স্ক্রোলিং কনফ্লিক্ট)
* **ফাইল:** `src/components/category-drawer/CategoryDrawer.tsx` (Lines 81–99)
* **ত্রুটির বিবরণ:**
  সোয়াইপ লিসেনারে শুধুমাত্র `deltaX < -60` চেক করা হচ্ছে, কোনো `deltaY` বা কোণ (angle) যাচাই করা হচ্ছে না।
  মোবাইল ইউজার যখন ক্যাটাগরি তালিকা নিচে স্ক্রোল করতে গিয়ে আঙুল সামান্য বাঁকা করবে (`deltaY = 150px, deltaX = -65px`), ড্রয়ারটি স্ক্রোল না হয়ে হুট করে বন্ধ হয়ে যাবে!
* **বাধ্যতামূলক সংশোধন:**
  - সোয়াইপ জেসচারে উলম্ব দূরত্ব যাচাই করুন: `Math.abs(deltaX) > Math.abs(deltaY) * 1.5` এবং `Math.abs(deltaX) > 50` হলেই কেবল সোয়াইপ-টু-ক্লোজ কার্যকর হবে।
